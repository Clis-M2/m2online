## Como usar

A Emy V2 não deve consumir a base bruta diretamente para decisões críticas. O conteúdo deve ser transformado em bases menores, versionadas e aprovadas por domínio:

1. Institucional e tom de voz;
2. Catálogo comercial;
3. Financeiro;
4. Suporte internet;
5. Suporte serviços adicionais;
6. Segurança, permissões e escalonamento;
7. Contratos de tools e fontes de verdade.

## Classificação de confiança

Toda informação extraída deve receber uma classificação:

- **Confirmado**: pode orientar atendimento, desde que não envolva preço/política sensível sem fonte oficial.
- **Referência atual**: usar apenas em resposta assistida ou com confirmação de fonte.
- **Projeto em evolução**: não prometer ao cliente.
- **Lacuna**: depende de validação com Clistenis/Íris/Nexo.

## Regra de ouro

A Emy pode explicar, orientar e consultar sistemas. Ela não pode inventar preço, prometer instalação, alterar contrato, liberar crédito, executar comando técnico sensível ou confirmar ação sem retorno da tool.
