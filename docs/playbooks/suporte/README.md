# Playbooks de Suporte — Emy V2

A Emy Suporte será construída por famílias de problema, não por respostas genéricas.

Cada playbook deve conter:

- sintomas;
- perguntas permitidas;
- dados automáticos necessários;
- dependências;
- árvore de decisão;
- testes seguros;
- comandos permitidos;
- comandos proibidos;
- critério de sucesso;
- critério de OS;
- prioridade;
- setor responsável;
- texto ao cliente;
- registro técnico;
- evidências;
- rollback;
- escalonamento.

## Playbooks prioritários

1. Internet totalmente offline.
2. Bloqueio financeiro.
3. LOS vermelho.
4. ONU sem energia.
5. Lentidão via Wi-Fi.
6. Lentidão via cabo.
7. Oscilação.
8. Incidente coletivo.
9. OS existente.
10. Cliente irritado/recorrência.

## Regra central

Diagnosticar antes de abrir OS, exceto quando houver risco físico, dano evidente, rompimento, incidente coletivo confirmado, procedimento inseguro ou política operacional determinando visita.
