# Catálogo Comercial M2 — Pendente de Validação

Este diretório deve conter o catálogo oficial usado pela Emy Comercial.

Enquanto este catálogo não estiver aprovado, a Emy não deve responder preços, descontos, fidelidade ou condições comerciais como verdade final.

## Arquivos recomendados

- `planos-internet.md`
- `servicos-adicionais.md`
- `taxas-e-fidelidade.md`
- `campanhas.md`
- `cobertura.md`
- `objecoes-comerciais.md`

## Campos mínimos por plano

- nome comercial;
- velocidade;
- valor mensal;
- taxa de instalação;
- fidelidade;
- roteador incluso ou não;
- benefícios;
- adicionais compatíveis;
- disponibilidade por área;
- status: ativo, suspenso, legado ou proposta.
